# 充电提醒 v1.0.0

首个公开版本。纯本地、不联网、不常驻后台的 Android 充电周期提醒。

## 功能

- **设备清单**：充电宝 / 手表 / 耳机 / 电动牙刷 / 剃须刀 / 相机电池 / 扫地机……
- **首页**：卡片流、进度环、剩余天数，按紧急程度排序；逾期红色、今天琥珀色
- **一键「已充电」**：自动从今天重排下一次；通知栏里也能直接操作
- **充电自适应**：记录时填剩余电量，按实际耗电速度调整间隔（单次 ±30%）
- **详情页**：平均间隔、间隔趋势柱状图、充电记录
- **外观**：深浅色跟随系统、4 套配色、Android 12 动态取色、渐变 / 相册背景（模糊 + 暗化）
- **设置**：默认间隔与提醒时间、免打扰、提醒强度、权限自检、JSON 导出 / 导入

## 安装

1. 下载下方的 `ChargeReminder-v1.0.0.apk`
2. 手机上允许「安装未知来源应用」/「安装外部来源应用」
3. 安装后打开，允许**通知权限**
4. 进入 `设置 → 权限自检`：开启**精确闹钟**、**电池优化**白名单
5. 国产 ROM（小米 / 华为 / OPPO / vivo）再到系统设置里允许**自启动**，省电策略设为**无限制**

支持 **Android 8.0（API 26）及以上**。

> 如果之前装过 debug 版，需要先卸载再装（签名不同），应用数据会清空；
> 卸载前先到 `设置 → 数据 → 导出 JSON` 备份，导出不含照片。

## 已知限制

- 没有桌面小组件
- 导出 JSON 不含照片
- 动态取色取的是系统壁纸颜色，不从自定义背景图里提取
- 仅中文
