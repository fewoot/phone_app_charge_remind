1. **首页**：能不能一眼看出「哪台设备还剩几天 / 谁逾期了」？
2. **新建**：从首页到「填完保存」要几步？哪些字段是必填？
3. **设置页**：有没有「权限自检 / 提醒时间 / 备份」这三样？入口深不深？
4. **通知**：能不能在通知里直接点「完成 / 推迟」，不用打开 App？
5. **外观**：主题能换几套？有没有「动态取色」？（用来判断加背景图的难度）

## Part B　需求清单

### 1. 基本设定

- **App 名字**：充电提醒
- **图标风格**：平面化极简风格
- **语言**：仅中文
- **桌面小组件**：以后再说
- **打开要密码/指纹**：不要

### 2. 设备与周期

先把你实际要管的设备列出来（这张表最重要）：不一定，以后会自己再添加

| #   | 设备   | 间隔  | 提醒时间 | 提前几天 | 备注           |
| --- | ------ | ----- | -------- | -------- | -------------- |
| 1   | 充电宝 | 14 天 | 09:00    | 0        | 示例，改成你的 |
| 2   | 手表   | 7 天  | 20:00    | 1        |                |
| 3   | 耳机   | 10 天 | 09:00    | 0        |                |
| 4   |        |       |          |          |                |
| 5   |        |       |          |          |                |

其他规则：

- 间隔单位：三种都支持
- 允许「一次性任务」吗（例：这周末给相机充电）：要
- 设备数量上限：不限

### 3. 首页

- 布局：卡片流（默认）
- 每张卡显示：设备名 + 进度条或进度环（默认）/ 剩余天数（默认）/ 上次充电日期 / 【已充电】按钮（默认），再加一个是否启用
- 排序：**按紧急程度（默认）** ，距离充电日最近的最靠上
- 逾期样式：红色 + 「逾期 N 天」（默认）
- 空状态：插画 + 「添加第一台设备」
- 额外想加的：______

### 4. 新建 / 编辑设备

- 必填：名称、间隔天数（默认）
- 选填：图标、颜色、提醒时间、提前天数、备注，可以调用拍照拍摄物品，代替图标，
- **预设模板**（选一个就带好默认值和图标）：充电宝 / 手表 / 耳机 / 电动牙刷 / 剃须刀 / 相机电池 / 扫地机 / 其他
- 保存后立刻排闹钟，不用再点「启用」（默认）

### 5. 设备详情页

- 充电历史列表（日期 + 距上次多少天）（默认）
- 平均间隔（默认）
- 下次提醒的具体时间（默认）
- 手动修改「上次充电时间」（默认，用来校准）
- 删除设备（二次确认）（默认）
- 历史图表：需要
- 同时还要加一个是否启用充电自适应，每次充电的时候，可以额外写一下现在剩下的电量，系统能够根据这个信息自动调整充电天数，因为不是所有的设备我都知道需要隔多少天

### 6. 提醒

- 默认提醒时间：**09:00**（可每台单独设）
- 提前提醒：0 天（默认）/ 1 天 / 3 天，每台可设
- 逾期后怎么催：
  - [ ] 逾期当天再提醒一次，之后不再烦
  - [ ] 逾期后每 3 天提醒一次（默认）
  - [x] 每天都提醒
- 通知按钮：**【已充电】+【推迟 3 天】**（默认）
- 免打扰时段：23:00–08:00 不响（默认，可关）
- 提醒强度：L2 普通通知（默认）/ L3 闹钟式（响到手动关）
- 权限被拒时：首页顶部黄条 + 「去授权」按钮（默认）
- 设置页要有「发一条测试通知」按钮（默认）

### 7. 外观（重点，决定「好不好看」）

**背景**

- [x] 无（纯色）
- [x] 预设渐变（3–5 套）
- [x] 相册选图（默认支持）
- 图片调整：模糊 0–25（默认 8）、暗化 0–70%（默认 45%）
- 背景跟随深浅色自动调暗（默认开）

**主题**

- 跟随系统 / 浅色 / 深色（默认：跟随系统）
- 动态取色（Android 12+，从壁纸取色）（默认开）
- 预设配色：4 套（默认）
- 强调色手动选：要 / 不要（默认：不要，MVP 够用）

**卡片**

- 圆角：大圆角（默认，24dp 左右）
- 半透明玻璃感：要（默认）/ 不要
- 字号：跟随系统（默认）

### 8. 设置页要包含哪些（勾选）

- [x] 外观：背景 / 主题 / 动态取色
- [x] 提醒：默认时间 / 提前天数 / 免打扰 / 提醒强度
- [x] 权限自检：通知权限 / 精确闹钟 / 电池优化 / 测试通知
- [x] 数据：导出 JSON / 导入 / 清空
- [x] 关于：版本 / 开源许可 / 隐私说明（不联网、不收集）
- [ ] 语言切换（默认不做，只有中文）
- [x] 默认间隔 / 默认提醒时间（默认做，省得每台都填）

### 9. 数据

- 全部本地存储，不联网、不要账号（默认）
- 导出：JSON 存到「下载」目录（默认）
- 导入：覆盖现有数据，导入前二次确认（默认）
- 卸载会丢数据 → 设置页提示「记得偶尔导出备份」（默认）

### 10. 明确不要（防止我加戏）

- 账号 / 云同步 / 注册
- 广告 / 埋点 / 统计
- 手机电量监控、充电曲线（以后想加再说）
- 多语言（除中文外）
- 复杂统计报表

### 11. 验收标准（改完我自己按这个测）

1. 装到手机上，能添加 3 台设备并看到倒计时
2. 把某台间隔改成 0 天 → 1 分钟内收到通知 → 在通知里点【已充电】→ 首页立刻变成「还有 N 天」
3. 换一张相册图片当背景 → 杀进程重开 App，背景还在
4. 重启手机 → 提醒还在（把提醒时间设成 5 分钟后验证）
5. 关掉通知权限 → 首页出现黄条提示，且不崩溃
