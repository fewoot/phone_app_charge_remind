# 充电提醒 · HTML 交互原型

这是正式写 Android 之前的**可点击原型**，用来确认界面和流程，不是最终 App。
原型定稿后已 1:1 实现为原生 Android 工程，见 [`android-app/`](../android-app/README.md)。

## 怎么打开

双击 `index.html`（推荐 Edge / Chrome）。

- 手机上看：把窗口拉窄到 560px 以下，会自动变成全屏手机比例
- 电脑上看：外面有一圈手机边框，页面会按窗口高度自动缩放
- 想一次看六个界面：打开 `preview.html`（首页 / 详情 / 设置 / 编辑 / 记录充电 / 深色）

## 可以点的东西

| 位置 | 操作 |
|---|---|
| 首页卡片 | 点卡片进详情；点右下「已充电」记录一次充电 |
| 卡片左下开关 | 启用 / 停用该设备（停用后置灰、不再提醒） |
| 右下角 ＋ | 添加设备：模板、图标、拍照/相册、颜色、间隔、提醒时间、自适应 |
| 首页右上齿轮 | 设置：主题 / 配色 / 背景 / 提醒 / 权限自检 / 数据 / 关于 |
| 设置 → 背景 → 图片 | 选一张本地照片，可调模糊和暗化（背景会存进浏览器本地） |
| 设置 → 发送一条测试通知 | 从顶部弹出通知，可直接点「已充电 / 推迟 3 天」 |
| 详情页 | 间隔趋势图、充电记录、编辑、删除 |
| 编辑页底部 | 保存（固定悬浮，不随页面滚动） |

## 已经做进原型的（对应需求清单）

- ✅ 首页卡片流：进度环、剩余天数、上次充电、下次提醒、启用开关、一键「已充电」
- ✅ 排序：距离充电日最近的排最上面，停用的排最后
- ✅ 逾期红色 +「逾期 N 天」，今天琥珀色 +「今天该充了」
- ✅ 定期（天/周/月）与一次性任务
- ✅ 快捷模板、emoji 图标、拍照/相册当图标、颜色
- ✅ 记录充电时填「剩余电量」→ **充电自适应**自动加减间隔，并给出解释
- ✅ 详情：平均间隔、次数、间隔趋势柱状图、历史记录
- ✅ 通知：到期提醒 + 「已充电 / 推迟 3 天」，可预览
- ✅ 设置：主题（跟随系统/浅/深）、4 套配色、背景（纯色/渐变/图片 + 模糊/暗化）、动态取色、默认间隔/时间/提前提醒、免打扰、提醒强度、逾期每天提醒、权限自检、导出/导入 JSON、清空
- ✅ 数据存本地（localStorage），刷新不丢

## 原型里是「假的」

- 通知不会真的定时弹（浏览器做不到），只能手动触发预览
- 「权限自检」的按钮只做状态切换，真机会跳系统设置
- 拍照按钮在电脑上是选文件，手机上才会调相机
- 导出的 JSON 是浏览器下载，真机会写到「下载」目录

## 数据 & 重置

数据存在浏览器 localStorage，键名 `charge-reminder-proto-v2`。

- 重置演示数据：设置 → 数据 → 清空所有数据
- 或按 F12 → Application → Local Storage → 删掉这条记录，刷新即可
